What should the 3D hero object represent?

ssscript uses their logo as a 3D icon. Validex needs something that represents metabolomics data auditing.

3D Molecule

A rotating metabolite molecule (ball-and-stick model). Spins idly, tilts toward mouse. Directly represents metabolomics.

3D App Icon (ssscript-style)

Validex logo extruded as a 3D rounded-square app icon. Exactly like ssscript — spins, tilts on hover, catches light.

3D Data Crystal

A glowing geometric crystal — abstract, represents data purity/clarity after validation. Rotates and refracts light.

Implementation note

All options use React Three Fiber + @react-three/drei (Three.js for React). The object floats, auto-rotates slowly, and tilts toward the mouse cursor — same interaction as ssscript.app.
