# Changelog

## 0.1.0 - Research Preview

- Added deterministic CSV ingestion, schema validation, strict API/CLI errors, and JSON-safe audit output.
- Added canonical frontend response handling and safe report rendering.
- Added reproducible frontend asset packaging and static parity verification.
- Added explicit optional AI controls, prompt/data boundary hardening, upload limits, privacy status, CORS, security headers, and dependency-risk classification.
- Added Phase 5 release-candidate process: CI, dependency audits, artifact inspection, external-validation manifest, release gates, and installed-wheel smoke checks.

Validex 0.1.0 is a research preview. It has synthetic benchmark and repository regression evidence, but no committed legally redistributable independent external-validation dataset.
